# 数据同步策略文档

> 本目录包含 AI 原生企业数据平台的**数据同步策略**相关文档。
> 技术本质收敛为 **两条策略**：数据库视图同步 + API 拉取同步。
> 不同系统（ERP / MES / SRM）是这两种策略上的**配置实例**，差异体现在：选哪种策略、优先顺序、同步频率、表/接口范围、特殊限制。
>
> 对应技术方案：《AI 原生企业数据平台产品技术设计方案》第 7 章 数据接入与异步任务架构。

## 核心概念速览

### 两条策略

| 策略 | 适用场景 | 技术手段 |
|---|---|---|
| **数据库视图同步** | 直连业务数据库（如 ERP SQL Server） | SQLAlchemy + 只读连接 → 全量/增量 SELECT → PostgreSQL Raw 物理表 |
| **API 拉取同步** | 通过 REST API 获取数据（如 MES、SRM） | httpx + 令牌桶限流 → 分页拉取 → PostgreSQL Raw JSONB 通用表 |

### 数据分层

```text
数据源 → Connector → Raw 层 → Clean 层 → Serving 层 → Agent / 数据目录
```

详见 [01-数据同步策略总览](./01-数据同步策略总览.md)。

### 三大数据源

| 数据源 | 策略 | 规模 | 梳理文档 |
|---|---|---|---|
| ERP (E10) | 数据库视图同步 | 8 域 103 张 P0 表 | `docs/数据梳理/ERP/梳理后/` |
| MES (LightMES) | API 拉取同步 | 25 个接口 | `docs/数据梳理/MES/` |
| SRM | API 拉取同步 | 8 类接口 | `docs/数据梳理/SRM/梳理后/` |
