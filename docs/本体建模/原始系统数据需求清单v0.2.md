# 原始系统数据需求清单 v0.2（ERP 精简版）

> **版本**：v0.2
> **日期**：2026-07-15
> **范围**：仅限 ERP (E10) 中 **物料 / 库存 / 订单 / 采购 / BOM** 五个模块
> **来源**：基于 [[原始系统数据需求清单|原始系统数据需求清单 v1.0]] 筛选提取
> **接入方式**：数据库直连同步

## 接入优先级

### 数据依赖关系

物料(ITEM) 是所有模块的基础，所有表均依赖 `ITEM_ID` 外键。

```
① 物料(ITEM) ──→ ② BOM ──→ ⑥ 制造工单(MO)
    │                │
    ├──→ ③ 库存       │
    │                │
    ├──→ ④ 采购(PO)   │
    │                │
    └──→ ⑤ 销售(SALE)
```

### 四阶段推进

| 阶段 | 模块 | 依赖 | 说明 |
|------|------|------|------|
| **P0 打地基** | ① 物料(ITEM) | 无 | 万物之基，所有模块的 FK 都指向 `ITEM` |
| **P1 结构+现状** | ② BOM + ③ 库存 | ITEM | BOM 树建起来，库存快照拉通，制造才有输入 |
| **P2 需求+供给** | ④ 采购(PO) + ⑤ 销售(SALE) | ITEM | 入向/出向订单独立，可与 P1 并行 |
| **P3 生产执行** | ⑥ 制造工单(MO) | ITEM + BOM + 库存 | 依赖 BOM 版本 + 库存齐套，最后接入 |

> **注意**：P1 和 P2 可并行推进。销售和采购数据链路相对独立，不互相阻塞。
