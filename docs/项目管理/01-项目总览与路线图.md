# 项目总览与路线图

> [!abstract] 项目名片
> | 项 | 内容 |
> |---|---|
> | 项目名称 | AI 原生企业数据平台（sk-mind） |
> | 一句话定义 | 汇聚企业分散数据，通过轻量语义本体和 Agent 能力，让业务人员可问、可查、可追溯 |
> | 目标客户 | 中小型制造企业（MES/ERP 数据域） |
> | 核心解决的问题 | 数据分散在 ERP/MES/WMS/Excel，没有统一查询入口；数据质量不可见；AI 回答缺乏可信依据 |
> | 当前阶段 | 阶段 1：可信数据底座（完成度约 60%） |
> | 项目总进度 | 约 28%（2026-07-20 更新，W29 推进 +7%） |

                    +------------------+
                    |   Agent 问答      |  阶段 3-4

## 阶段路线图

| 阶段   | 目标                      | 主要交付物                                           | 预估时间  | 状态      |
| ---- | ----------------------- | ----------------------------------------------- | ----- | ------- |
| 阶段 0 | 明确试点数据源、业务对象、问题和边界      | 数据源盘点表、业务对象清单、试点问题清单、权限初稿                       | 1 周   | ✅ ~80%  |
| 阶段 1 | 建成可信数据底座                | 数据源管理、接入任务追踪、数据目录、数据质量、权限审计、前端控制台      | 7-8 周 | 🔄 ~60% |
| 阶段 2 | 建立轻量语义本体和业务关系图谱         | 语义对象/属性/关系模型、DataMapping、BusinessGraphEdge、图谱查询 | 4 周   | ⬜ 0%    |
| 阶段 3 | 建立指标规则和 Agent 可信查询分析    | Agent 会话/消息/工具调用、指标口径管理、工具注册、问题规划与审计            | 4 周   | ⬜ 0%    |
| 阶段 4 | 建立 Agent 建议、预警、人工确认协同闭环 | 建议与预警草稿、协同待办与确认闭环                               | 2 周   | ⬜ 0%    |
| 全链路  | 形成可演示、可部署、可交付版本         | 验收清单、样例数据、演示脚本、部署说明                             | 1 周   | ⬜ 0%    |

## 团队与角色

| 角色 | 职责 |
|---|---|
| 产品 / 数据顾问 | 数据盘点、业务对象梳理、需求澄清 |
| 后端开发 | FastAPI 后端、ORM 模型、连接器、Agent 链路 |
| 前端开发 | Vue 3 管理控制台、数据浏览、Agent 交互 |
| QA / 全栈 | 集成验收、端到端测试、部署验证 |
| DevOps | Docker Compose 部署、CI/CD、环境维护 |
