## 当前问题

### ISS-001：执行链路为 stub，未接入真实连接器

| 字段 | 内容 |
|---|---|
| 发现周期 | W27（6/30-7/6） |
| 发现人 | 代码审计 |
| 关联任务 | [[02-任务执行追踪表#T06|T06]], [[02-任务执行追踪表#T07|T07]], [[02-任务执行追踪表#T08|T08]], [[02-任务执行追踪表#T09|T09]] |
| 类型 | 🔴 卡点 |
| 严重程度 | 高（阻塞 Excel 导入和数据接入链路） |
| 状态 | 🆕 新建 |

**描述**
当前接入任务执行 API（`POST /ingestion-tasks/{task_id}/execute`）通过 RQ 队列调用的 worker 任务是 `run_echo_sync`——一个仅打印任务名称的占位函数。真实的 SqlServerConnector、Sheet/CSV 连接器、数据写入逻辑均未接入。

**影响**
- T06 虽然 API 完成度 85%，但核心执行链路不通
- T07 的 SqlServerConnector 代码已完成，但无法在 worker 中验证
- T08、T09 完全被阻塞
- 数据浏览页只能读取已有测试数据，无法看到新导入数据

**建议方案**
1. 将 `run_echo_sync` 替换为真实的 `run_ingestion_task` 函数
2. 该函数读取 IngestionTask 的 config，根据 source_type 选择连接器
3. 先接入 SqlServerConnector，再逐步接入文件连接器
4. 在 RQ Worker 中以同步方式运行连接器，FastAPI 层仅做任务调度

**建议优先级**：P1 本周处理

**前置依赖**：无（T06 API 和 T07 SqlServerConnector 代码均已就绪，只需串联）

**预估工时**：1-2 人天
