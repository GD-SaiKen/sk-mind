### ISS-001：ERP 数据库直连被拒绝，需调整数据接入策略 ^iss-001

| 字段 | 内容 |
|---|---|
| 发现周期 | W27 发现 → W29 升级 |
| 发现人 | 黄工（ERP 运维）正式回复 |
| 关联任务 | [[02-任务执行追踪表#T06|T06]], [[02-任务执行追踪表#T07|T07]], [[02-任务执行追踪表#T08|T08]], [[02-任务执行追踪表#T09|T09]] |
| 类型 | 🔴 卡点 |
| 严重程度 | 高（强制改变数据接入路径） |
| 状态 | 🔄 处理中 |

**描述**
W29 收到 ERP 运维黄工正式回复，分两点：

**生产库直连**：❌ 明确拒绝。原因是违反信息安全保密协议，直连存在 5 大类风险（误删/篡改生产数据、拖垮性能、商业数据泄露、缺乏审计、合规违规）。不走审批——运维直接拒绝。

**副本库只读**：⏳ 等防火墙安装后，可走审批申请中转服务器只读账号。审批链路：直属上司欧阳慧娟经理评估 → 说明应用场景/是否连公网/使用人员保密协议。防火墙尚未安装，中转服务器未配置。

**关键转折**
黄工同时确认：**ERP 客户端支持批量导出 Excel**，可导出物料主数据、生产工单、出入库单据、库存报表、购销订单、成本明细等**全模块业务单据**。

**影响**
- 原计划"SqlServer 直连 → 平台自动同步"路径短期走不通
- SqlServerConnector 代码可能仅用于测试环境或中转方案
- **数据接入主路径必须转向 Excel 批量导入**（T07 Excel 连接器 + T08 Excel 导入升为 P0）
- T06 执行链路的 Worker 实现需从 `run_echo_sync` 改为优先支持文件连接器

**建议方案**
1. **短期**：Excel 导入作为主路径——T07/T08 优先级提到最高，先跑通"ERP 导出 Excel → 平台导入 → Raw 层落库"
2. **中期**：副本库只读方案——等防火墙和中转服务器到位后，SqlServerConnector 用于连接副本库，作为自动化补充
3. **汇报口径**：生产库直连被拒（不可争取）/ Excel 导出已确认可用（不阻塞）/ 副本库只读等防火墙

**建议优先级**：P0 立即调整

**前置依赖**：无——Excel 导出路径已确认可用

**预估工时**：策略调整 0.5 人天，T07/T08 提前开发 +3 人天
