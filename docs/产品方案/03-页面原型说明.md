## 1. 原型设计目标与实施状态

### 1.1 设计目标

基础平台页面原型的目标是支撑以下工作：

- 让平台管理员能看到基础平台整体运行状态。
- 让数据负责人能登记数据源、跟踪接入任务、维护字段说明和处理质量问题。
- 让业务用户能通过数据目录理解平台中已有数据。
- 让语义建模人员能维护对象、属性、关系、映射和对象行动策略。
- 让审计人员能查看数据访问和 Agent 调用记录。
- 让 Agent 使用者能在权限范围内查询数据，并看到来源、质量和限制说明。

```text

→ 权限控制 → 语义映射 → 关系图谱 → Agent 数据服务
```

## 2. 页面设计原则

基础平台是企业数据治理和运营工具，页面应遵循以下原则：

| 原则 | 说明 |
| --- | --- |
| 状态优先 | 列表页优先展示状态、负责人、更新时间和异常 |
| 来源可见 | 数据表、字段、质量、语义映射和 Agent 回答都应能追踪来源 |
| 操作可控 | 高风险操作需要确认，Agent 操作需要权限和审计 |
| 信息密度适中 | 面向运营和治理场景，页面应紧凑、可筛选、可批量处理 |
| 异常可处理 | 不只展示失败，还要展示原因、影响范围和下一步动作 |
| 语义可理解 | 尽量让业务人员看到业务对象、字段说明和映射关系，而不是只看到技术字段 |
| Agent 有边界 | Agent 入口必须展示权限范围、数据质量和来源限制 |

## 3. 全局导航结构

### 3.1 页面框架

原型采用左侧可折叠导航 + 顶部全局栏 + **浏览器式标签栏** + 面包屑 + 内容区的五层结构：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏: [收起侧边栏] [搜索框...]   [测试环境] [🔔] [?] [👤管理员] │
├──────────────────────────────────────────────────────────────┤
│ 面包屑: 首页 > 接入任务 > SAP 销售订单同步                      │
├──────────────────────────────────────────────────────────────┤
│ 标签栏: [🏠 首页] [📋 接入任务 ×] [📊 数据表 ×]                │
├──────────────┬───────────────────────────────────────────────┤
│ 左侧导航     │ 内容区                                         │
│ (可折叠)     │  筛选 / 操作区 / 列表 / 详情                  │
│              │                                               │
│ 🏠 首页      │                                               │
│ 🗄 数据源    │                                               │
│ 📋 接入任务  │                                               │
│ 📊 数据表    │                                               │
│ 📖 数据目录  │                                               │
│ 🛡 数据质量  │                                               │
│ 👤 权限审计  │                                               │
│ 🧠 语义模型  │                                               │
│ 🔗 关系图谱  │                                               │
│ 🤖 Agent服务 │                                               │
│ ⚙ 系统设置  │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

### 3.2 左侧导航

| 一级导航 | 图标 | 路由 | 二级页面 |
|---|---|---|---|
| 首页 | Home | `/` | 运行状态 / 待处理事项 / 最近任务 |
| 数据源 | Database | `/datasources` | 列表 / 详情 `/datasources/:id` |
| 接入任务 | ListTodo | `/tasks` | 列表 / 详情 `/tasks/:id` |
| 数据表 | Table2 | `/tables` | 列表 / 详情 `/tables/:id` |
| 数据目录 | BookOpen | `/catalog` | 全部 / 财务 / 销售 / 生产 / 人事 |
| 数据质量 | ShieldCheck | `/quality` | 质量规则 / 执行记录 / 问题清单 |
| 权限审计 | User | `/permissions` | 用户/角色/部门/权限/敏感字段/审计日志 |
| 语义模型 | Brain | `/semantic` | 业务对象/属性/关系/映射/行动策略 |
| 关系图谱 | Network | `/graph` | 关系边列表/查询/确认 |
| Agent 服务 | Bot | `/agent` | Agent查询/工具管理/调用记录 |
| 系统设置 | Settings | `/settings` | 字典/标签/状态/参数 |

侧边栏支持折叠（`PanelLeftClose` / `PanelLeftOpen` 按钮），折叠后仅显示图标。

### 3.3 浏览器式标签栏

原型实现了类似 IDE 的标签式导航——通过侧边栏点击打开的页面以标签形式出现在顶栏下方：

- 每个标签显示图标 + 页面名称
- 当前激活标签高亮（白底 + 蓝色下划线）
- 非激活标签可点击切换，右侧 `×` 关闭
- 至少保留一个标签，关闭当前标签自动切换到右侧相邻标签
- 面包屑始终显示当前页在导航树中的路径

### 3.4 顶栏

顶栏包含：

- 侧边栏折叠/展开按钮。
- 全局搜索框（占位符："搜索数据源、数据表、数据集、字段..."）。
- 环境标识 Badge（测试环境 / 生产环境）。
- 通知铃铛图标。
- 帮助问号图标。
- 当前用户头像 + 姓名 + 邮箱（管理员 / admin@company.com）。

## 4. 通用页面结构

### 4.1 列表页结构

原型中所有列表页遵循统一的筛选 + 统计 + 表格模式：

```text
[页面小标签行]（部分页面有子Tab: 全部 | 财务 | 销售 ...）

筛选区: [🔍 搜索框...] [状态▼] [类型▼]           [+ 新建按钮]
统计卡片: ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
          │ 总数  │ │ 成功  │ │ 警告  │ │ 失败  │
          │  12   │ │  10   │ │   1   │ │   1   │
          └──────┘ └──────┘ └──────┘ └──────┘

数据表格:
  名称 | 来源 | 状态 | 时间 | 数量 | 操作(👁查看 ▶执行 🔄重试 ⏻停用)
─────────────────────────────────────────────────────────
分页: < 1 2 3 >
```

### 4.2 详情页结构

详情页采用面包屑 + 标题区 + 摘要卡 + Tabs 布局：

```text
面包屑: 接入任务 > SAP 销售订单同步
标题区: [任务名] [状态Badge] [结果Badge]    [▶立即执行] [🔄重试] [编辑] [⏻停用]
摘要卡: ┌────┬────┬────┬────┬────┐
        │方式│负责│最近│成功│失败│
        └────┴────┴────┴────┴────┘

Tabs: [当前配置] [批次列表(3)] [错误清单(2)] [产出数据表] [执行日志]
        ── 选中的 Tab 内容 ──
```

### 4.3 统计卡片的"三层结构"（v0.2 新增）

首页和列表页的统计卡片采用认知层 → 数据层 → 元数据层的三层信息架构：

```
┌──────────────────────┐
│ 认知层: 图标 + 标题 + 状态标识       │  用户第一眼识别"这是什么"
├──────────────────────┤
│ 数据层: 大数字 + 变化趋势            │  核心数值
├──────────────────────┤
│ 元数据/操作层: 附加信息 + 查看详情→    │  辅助信息 + 导航入口
└──────────────────────┘
```

## 5. 首页

### 5.1 页面目标

首页用于让平台管理员和数据负责人快速了解基础平台运行情况，发现异常并进入处理页面。

### 5.2 子标签

首页内部有 3 个子标签：**运行状态** | **待处理事项** | **最近任务**。

### 5.3 运行状态标签

**布局**：3 列响应式网格（`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`），每列一张卡片。

**卡片字段清单**（以数据源卡片为例）：

| 层级 | 字段 | 示例值 |
|---|---|---|
| 认知层 | 图标 + 标题 + 状态标识 | 🗄 数据源 · 正常（绿点） |
| 数据层 | 运行状态 / 当前状态 / 最后同步 | — / 正常 / 10:00 |
| 元数据层 | 附加信息 + 查看详情→ | 连接池 5/10 · 查看详情↗ |

**6 类统计卡片**（v0.2 已实现 3 类，其余预留）：

| 卡片 | 认知层 | 数据层字段 |
|---|---|---|
| 数据源 | 🗄 Database | 运行状态 / 当前状态 / 最后同步 |
| 接入任务 | 📋 ListTodo | 总数 / 成功 / 失败 |
| 数据表 | 📊 Table2 | 总数 / 启用Agent / 总记录 / 异常 |
| 数据质量 | 🛡 ShieldCheck | 通过 / 警告 / 异常（预留） |
| 语义模型 | 🧠 Brain | 对象 / 映射 / 关系（预留） |
| Agent 服务 | 🤖 Bot | 查询次数 / 成功率（预留） |

**快捷入口栏**（6 个 Button）：

```text
[+ 新增数据源] [📋 创建接入任务] [📖 查看数据目录] [🔍 执行质量检查] [🤖 进入Agent查询] [⚙ 系统设置]
```

### 5.4 待处理事项标签

待处理事项列表（预留 mock 数据）：

| 类型 | 内容 | 操作 |
|---|---|---|
| 接入失败 | 财务月报同步任务执行失败 | 查看详情→ |
| 解析失败 | 3 个 Excel 文件解析失败 | 查看文件→ |
| 质量问题 | 金额格式检查发现 12 个问题 | 查看问题→ |
| 待确认关系 | 5 条 AI 生成的关系边待确认 | 查看关系→ |

### 5.5 最近任务标签

最近 5 条接入任务的简化列表，点击跳转任务详情。

## 7. 接入任务模块

### 7.1 接入任务列表

```text
接入任务
├─ 主操作：[+ 创建任务]
├─ 筛选区：🔍搜索(名称/数据源) [状态▼(全部/成功/部分成功/失败)]
├─ 统计卡片：任务总数 / 执行成功 / 部分成功 / 执行失败
└─ 表格列：
   ├─ 任务名称（可点击 → 详情，蓝色链接）
   ├─ 数据源（可点击 → 数据源详情，蓝色链接）
   ├─ 接入方式
   ├─ 状态（Badge）
   ├─ 最近执行时间
   ├─ 最近结果（Badge: 成功/失败/部分成功）
   ├─ 成功数量（绿色数字 + 千分位）
   ├─ 失败数量（红色数字 if >0）
   └─ 操作：👁查看 ▶执行 🔄重试(仅异常) ⏻停用
```

### 7.2 任务详情

5 个 Tabs：

| Tab | 内容 |
|---|---|
| **当前配置** | 双列布局：任务名称 / 数据源 / 接入方式 / 执行频率 / 负责人 / 创建时间 / 更新时间 / 目标表 |
| **批次列表** | 表格：批次号 / 开始时间 / 结束时间 / 状态Badge / 数据量(千分位) / 错误数 / [查看详情] |
| **错误清单** | 错误卡片列表（红底）：每张含 文件名/行号/字段/错误类型/错误说明/建议处理 六段信息 |
| **产出数据表** | 数据表链接卡片：表名 + Layer Badge + 记录数 + 字段数 + [查看详情→] |
| **执行日志** | 等宽字体日志行：`[时间] 开始执行...` `[时间] 连接成功` `[时间] 拉取完成` `[时间] 写入完成` |

### 7.3 操作按钮行为

| 按钮 | 行为 |
|---|---|
| ▶ 立即执行 | 触发任务执行（POST /execute），跳转批次列表 |
| 🔄 重试 | 仅异常状态显示，创建新批次重试 |
| 编辑配置 | 打开编辑表单（弹窗或侧边抽屉） |
| ⏻ 停用 | 确认后停用，按钮变为"启用" |
| 👁 查看 | 跳转详情页 |

## 16. 核心流程页面串联

### 16.1 数据接入到 Agent 可用

```text
数据源列表 → 新增数据源 → 创建接入任务 → 任务详情
→ 批次详情 → 数据表详情 → 字段说明维护 → 数据目录详情
→ 权限配置 → Agent 可用标识 → Agent 查询入口
```

### 16.2 Excel 批量导入

```text
数据源列表 → 新增 Excel 数据源 → 创建 Excel 接入任务
→ 上传模板样本 → 确认字段解析 → 配置目录 → 执行批量导入
→ 查看批次详情 → 查看错误清单 → 查看产出数据表
```

### 16.3 语义映射到图谱

```text
数据表详情 → 选择字段 → 创建或选择业务对象 → 创建对象属性
→ 建立 DataMapping → 定义 SemanticRelation → 生成 BusinessGraphEdge
→ 查看关系边列表 → Agent 查询关系路径
```

### 16.4 数据质量到 Agent 提示

```text
数据表详情 → 执行质量检查 → 查看问题清单 → 更新质量状态
→ 数据目录展示质量状态 → Agent 查询读取质量状态 → Agent 回答说明数据限制
```

## 17. 空状态与异常状态

### 17.1 空状态

| 页面 | 空状态文案 | 主操作 |
| --- | --- | --- |
| 数据源列表 | 当前还没有数据源 | 新增数据源 |
| 接入任务列表 | 当前还没有接入任务 | 创建接入任务 |
| 数据表列表 | 当前还没有接入数据 | 去执行接入任务 |
| 数据目录 | 当前还没有可用数据集 | 查看数据表 |
| 质量规则 | 当前还没有质量规则 | 创建规则 |
| 语义对象 | 当前还没有业务对象 | 创建业务对象 |
| 关系图谱 | 当前还没有关系边 | 配置关系映射 |
| Agent 调用记录 | 当前还没有 Agent 调用记录 | 进入查询入口 |

### 17.2 异常状态

| 异常 | 页面处理 |
| --- | --- |
| 数据源不可连接 | 展示失败原因、检测时间、负责人和重试入口 |
| 接入任务失败 | 展示失败批次、日志、错误清单和重试入口 |
| Excel 解析失败 | 展示文件名、行列位置、错误字段和修正建议 |
| 数据质量异常 | 展示问题字段、样例、影响范围和处理状态 |
| 权限不足 | 展示无权限原因和数据负责人 |
| 语义映射冲突 | 展示冲突字段、冲突对象和待确认入口 |
| 关系边低可信 | 展示生成方式、证据和人工确认入口 |
| Agent 查询失败 | 展示失败原因、使用工具和可联系负责人 |

### 17.3 部分成功状态

接入任务、批量导入、质量检查都可能部分成功。页面必须展示：

- 成功数量。
- 失败数量。
- 跳过数量。
- 已入库数据。
- 未入库数据。
- 是否影响 Agent 使用。
- 下一步处理建议。

## 18. 页面级验收标准

### 18.1 总体验收

页面原型需要满足：

- 左侧导航覆盖基础平台所有一级模块。
- 浏览器式标签栏支持多页面并行操作和关闭。
- 首页能展示基础平台状态和异常入口（三层卡片结构）。
- 数据源到 Agent 可用的核心流程可以在页面之间串联。
- 接入任务列表含统计卡片/筛选/执行/重试/停用操作。
- 接入任务详情含 5 个 Tab（配置/批次/错误/数据表/日志）。
- Excel 批量导入流程有样本确认、批量执行和错误清单。
- 数据表、数据目录、数据质量和权限页面能支撑基础治理。
- 语义模型页面能支撑对象、属性、关系、映射和行动策略维护。
- 关系图谱页面能支撑 BusinessGraphEdge 查询和确认。
- Agent 数据服务页面能展示回答、来源、质量、权限和审计。
- 空状态、异常状态和部分成功状态都有明确处理方式。
