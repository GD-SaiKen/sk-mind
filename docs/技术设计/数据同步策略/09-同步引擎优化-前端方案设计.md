# 09-同步引擎优化：前端方案设计

> **背景**：后端方案 [[08-同步引擎优化方案-d2a对标]] 识别出 6 个缺口（对账机制、Schema 漂移、隔离区、定时调度、软删除、映射层）。本文档设计对应的前端页面、组件、API 层和类型定义，确保后端能力有 UI 承接、用户可感知可操作。
>
> **设计原则**：新增功能尽量融入现有页面结构（Tab/弹窗），不新建独立页面路由，除非交互复杂度确实需要。复用现有 CRUD 组件体系（`Table`/`Form`/`Crud`）和 Element Plus 组件。

## 一、现有前端结构分析

### 1.1 页面与路由

| 路由 | 页面 | 功能 |
|---|---|---|
| `/ingestion` | `ingestion-task/list.vue` | 任务列表 + 统计卡片 + 行内进度 |
| `/ingestion/create` | `ingestion-task/create.vue` | 创建/编辑任务（数据源选择 + 接口勾选 + 调度配置） |
| `/ingestion/:id` | `ingestion-task/detail.vue` | 任务详情（当前配置 + 执行记录 + 日志弹窗） |
| `/ingestion/:taskId/batch/:batchId` | `ingestion-task/batch-detail.vue` | 批次详情（摘要 + 错误清单） |
| `/data-sources/:id` | `data-sources/detail.vue` | 数据源详情（基本信息 + 系统状态 + 接入任务 + 产出表） |

### 1.2 API Service 层

`frontend/src/api/services/ingestion.ts` 中的 `IngestionService` 类已封装：

- Task CRUD：`getList`/`get`/`create`/`createApiTask`/`update`/`delete`/`enable`/`disable`
- 执行控制：`execute`/`backfill`/`quickFill`/`getTimeRange`
- Batch 查询：`getBatches`/`getBatch`/`getBatchProgress`/`getBatchErrors`
- Batch 操作：`retryBatch`/`cancelBatch`/`rollbackBatch`
- SSE 进度流：`streamProgress`

### 1.3 类型定义

`frontend/src/api/types.ts` 已有 `IngestionTask`/`IngestionBatch`/`ImportError`/`BatchProgress`/`ApiInterfaceItem` 等类型。

### 1.4 组件体系

- `Crud` = `TableFilters` + `Table` + `Pagination` 组合
- `Form` = 分区表单（支持 `field`/`section` 级 `hidden` 动态显隐）
- `ColumnSchema` 支持 `text`/`tag`/`date`/`custom`/`action` 等列类型
- `FormField` 支持 `input`/`select`/`radio`/`switch`/`date`/`number`/`readonly`/`custom`

```typescript
// JSON.parse 容错：后端可能返回 object（无需 parse）或 string（需 parse）
function formatRawJson(raw: unknown): string {
  if (typeof raw === 'object' && raw !== null) {
    return JSON.stringify(raw, null, 2)
  }
  if (typeof raw === 'string') {
    try { return JSON.stringify(JSON.parse(raw), null, 2) }
    catch { return raw }
  }
  return String(raw ?? '')
}
```

```typescript
const cronPreset = ref('*/30 * * * *')

function onCronPresetChange(val: string) {
  if (val !== 'custom') {
    form.value.cronExpression = val
  }
}

// 调用后端预览下次执行时间
async function previewNextRun() {
  if (form.value.scheduleType !== 'cron' || !form.value.cronExpression) {
    nextRunPreview.value = ''
    return
  }
  try {
    const result = await ingestionService.previewCron(form.value.cronExpression)
    nextRunPreview.value = result.nextRun?.slice(0, 16).replace('T', ' ') || '无效表达式'
  } catch {
    nextRunPreview.value = '表达式无效'
  }
}
```

### 11.2 数据加载

```typescript
async function loadReconciliations() {
  try {
    const res = await ingestionService.getReconciliations(taskId, { pageSize: 50 })
    reconciliations.value = res.items ?? []
  } catch (e) { console.error('加载对账记录失败:', e) }
}

async function loadSchemaChanges() {
  try {
    const res = await ingestionService.getSchemaChanges(taskId)
    schemaChanges.value = res.items ?? []
  } catch (e) { console.error('加载Schema变更失败:', e) }
}

async function loadQuarantine() {
  try {
    const [listRes, statsRes] = await Promise.all([
      ingestionService.getQuarantine(taskId, { ...quarantineFilter, pageSize: 50 }),
      ingestionService.getQuarantineStats(taskId).catch(() => null),
    ])
    quarantineList.value = listRes.items ?? []
    if (statsRes) quarantineStats.value = statsRes
  } catch (e) { console.error('加载隔离区数据失败:', e) }
}

// 在 load() 中追加调用
async function load() {
  task.value = await ingestionService.get(taskId)
  const b = await ingestionService.getBatches(taskId, { pageSize: 50 })
  batches.value = b.items
  // 并行加载新增数据，await 确保渲染前数据就绪
  await Promise.all([
    loadReconciliations(),
    loadSchemaChanges(),
    loadQuarantine(),
  ])
}
```
