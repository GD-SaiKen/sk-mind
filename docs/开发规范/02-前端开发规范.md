# 02 — 前端开发规范

> 技术栈：Vue 3 + Vite + TypeScript + Element Plus + SCSS。
> 通用约定（命名、Import、文件组织等）见 [01-通用规范](./01-通用规范.md)。

---

## 1. Vue 组件规范

### 1.1 组件命名

- 组件文件使用 **kebab-case**（与通用规范一致）
- 在模板中使用组件时，使用 **PascalCase** 或 **kebab-case**，同一项目内保持一致

```
✅ components/status-tag/index.vue
✅ components/page-header/index.vue
✅ <StatusTag :status="row.status" />
✅ <status-tag :status="row.status" />
```

### 1.2 单文件组件结构

严格按以下顺序组织 `<template>`、`<script>`、`<style>`：

```vue
<template>
  <!-- 模板内容 -->
</template>

<script setup lang="ts">
// 逻辑内容
</script>

<style lang="scss" scoped>
// 样式内容
</style>
```

### 1.3 `<script>` 内部顺序

```vue
<script setup lang="ts">
// 1. 类型导入
import type { DataSource } from '@/types/data-source';

// 2. 第三方库导入
import { ElMessage, ElMessageBox } from 'element-plus';
import { computed, onMounted, ref, watch } from 'vue';

// 3. 项目内部导入
import { deleteDataSource, fetchDataSourceList } from '@/api/data-source';
import { usePermission } from '@/composables/use-permission';
import { StatusTag } from './components/status-tag';

// 4. Props / Emits 定义
const props = withDefaults(defineProps<{
  sourceId?: number;
  readonly?: boolean;
}>(), {
  sourceId: undefined,
  readonly: false,
});

const emit = defineEmits<{
  submit: [data: Record<string, unknown>];
  cancel: [];
}>();

// 5. 响应式状态
const loading = ref(false);
const dataList = ref<DataSource[]>([]);
const searchKeyword = ref('');

// 6. 计算属性
const filteredList = computed(() =>
  dataList.value.filter(item =>
    item.name.includes(searchKeyword.value)
  )
);

// 7. 方法
async function loadData() {
  loading.value = true;
  try {
    const res = await fetchDataSourceList();
    dataList.value = res.data.items;
  } finally {
    loading.value = false;
  }
}

// 8. 生命周期
onMounted(() => {
  loadData();
});

// 9. 监听器
watch(() => props.sourceId, (newId) => {
  if (newId) loadData();
});
</script>
```

### 1.4 Props 与 Emits

- 使用 TypeScript 泛型声明，不用运行时声明

```vue
<!-- ✅ 推荐：类型声明 -->
<script setup lang="ts">
const props = withDefaults(defineProps<{
  title: string;
  count?: number;
  items: DataSource[];
}>(), {
  count: 0,
});

const emit = defineEmits<{
  change: [id: number];
  delete: [id: number, name: string];
}>();
</script>

<!-- ❌ 不推荐：运行时声明 -->
<script setup>
const props = defineProps({
  title: { type: String, required: true },
});
</script>
```

### 1.5 模板规范

- 属性超过 3 个时，每个属性独占一行
- 指令 (`v-if`, `v-for`, `v-model`) 放在最前面
- 自闭合标签使用 `<tag-name />` 形式

```vue
<!-- ✅ 属性少，单行 -->
<el-input v-model="keyword" placeholder="请输入数据源名称" />

<!-- ✅ 属性多，换行 -->
<el-table
  v-loading="loading"
  :data="filteredList"
  :default-sort="{ prop: 'updatedAt', order: 'descending' }"
  border
  stripe
  @selection-change="handleSelectionChange"
>
  <el-table-column type="selection" width="50" />
  <el-table-column prop="name" label="数据源名称" min-width="180" />
  <el-table-column prop="status" label="状态" width="100" />
</el-table>

<!-- ❌ 属性混在一起 -->
<el-table v-loading="loading" :data="filteredList" border stripe :default-sort=... >
</el-table>
```

## 2. TypeScript 规范

### 2.1 类型定义

- 优先使用 `interface`，需要联合类型或映射类型时使用 `type`
- 类型文件放在 `src/types/` 目录下，按模块拆分

```typescript
// src/types/data-source.ts
export interface DataSource {
  id: number;
  name: string;
  sourceType: 'database' | 'api' | 'file';
  status: 'active' | 'inactive' | 'error';
  owner: string;
  createdAt: string;
  updatedAt: string;
}

export type DataSourceFormData = Omit<DataSource, 'id' | 'createdAt' | 'updatedAt'>;
```

### 2.2 避免 `any`

- 禁止使用 `any`，确实无法确定类型时使用 `unknown`
- API 返回值必须声明类型

```typescript
// ❌
const data: any = await fetchData();

// ✅
const data: DataSource[] = await fetchData();

// ✅ 确实未知时
function parseResponse(raw: unknown): ParsedData { ... }
```

### 2.3 泛型命名

- 单泛型使用 `T`，多泛型使用有意义的前缀如 `TItem`、`TKey`

```typescript
export function usePagination<TItem>(
  fetchFn: (page: number) => Promise<{ items: TItem[]; total: number }>
) { ... }
```

## 3. Element Plus 使用规范

### 3.1 组件选择

- 表格：`el-table`（不用 `el-table-v2` 除非性能确实有问题）
- 表单：`el-form` + `el-form-item`
- 弹窗：`el-dialog`（简单确认用 `ElMessageBox`）
- 抽屉：`el-drawer`（详情或新增表单侧滑）
- 标签：`el-tag`（状态展示）
- 分页：`el-pagination`
- 通知：`ElMessage`（操作反馈）/ `ElNotification`（系统通知）

### 3.2 表格列宽

- `type="selection"` 列宽 `50`
- 状态列宽度 `80-100`
- 时间列宽度 `160-180`
- 操作列宽度按按钮数量 × 40 估算

### 3.3 表单校验

- 校验规则写在 `el-form` 的 `rules` prop 中，与后端校验保持一致

```vue
<el-form
  ref="formRef"
  :model="formData"
  :rules="rules"
  label-width="120px"
>
  <el-form-item label="数据源名称" prop="name">
    <el-input v-model="formData.name" placeholder="请输入数据源名称" />
  </el-form-item>
</el-form>

<script setup lang="ts">
const rules: FormRules = {
  name: [
    { required: true, message: '请输入数据源名称', trigger: 'blur' },
    { max: 128, message: '名称不能超过 128 个字符', trigger: 'blur' },
  ],
};
</script>
```

## 4. SCSS 规范

> 本项目统一使用 SCSS，不使用纯 CSS。遵循以下约定。

### 4.1 属性书写顺序

按以下顺序排列（继承自通用规范）：

1. **定位**：`position` / `top` / `right` / `bottom` / `left` / `z-index` / `float` / `display`
2. **尺寸**：`width` / `height` / `min-width` / `max-width` / `min-height` / `max-height`
3. **盒模型**：`margin` / `padding`
4. **边框**：`border` / `border-radius` / `box-shadow`
5. **排版**：`font-size` / `font-weight` / `color` / `line-height` / `text-align` / `text-indent`
6. **背景**：`background-color` / `background-image` / `background-position` / `background-size`
7. **其他**：`cursor` / `opacity` / `transition` / `transform` / `overflow`

```scss
.data-table {
  // 1. 定位
  position: relative;
  display: flex;

  // 2. 尺寸
  width: 100%;
  max-width: 1200px;

  // 3. 盒模型
  margin: 0 auto;
  padding: 16px 0;

  // 4. 边框
  border: 1px solid #ebeef5;
  border-radius: 4px;

  // 5. 排版
  font-size: 14px;
  color: #303133;
  line-height: 1.5;

  // 6. 背景
  background-color: #fff;

  // 7. 其他
  cursor: pointer;
  transition: border-color 0.3s;
}
```

### 4.2 嵌套规则

- 子元素选择器嵌套在父级内，使用 SCSS 嵌套语法
- **父子关系**：直接子元素用 `>`，后代用空格
- **伪类/伪元素**：使用 `&` 符号嵌套在目标选择器内
- **状态修饰符**：使用 `&` 符号（如 `&:hover`、`&.is-active`、`&--disabled`）
- 嵌套深度**不超过 3 层**

```scss
// ✅ 正确的嵌套
.ingestion-task-card {
  display: flex;
  padding: 16px;
  border: 1px solid #ebeef5;
  border-radius: 8px;

  // 直接子元素
  > .task-header {
    display: flex;
    align-items: center;
    justify-content: space-between;
    margin-bottom: 12px;

    .task-name {
      font-size: 16px;
      font-weight: 600;
      color: #303133;
    }

    .task-status {
      font-size: 12px;

      // 子元素内使用 & 表示父选择器
      &.is-running {
        color: #409eff;
      }

      &.is-success {
        color: #67c23a;
      }

      &.is-failed {
        color: #f56c6c;
      }
    }
  }

  > .task-body {
    display: flex;
    gap: 24px;

    .stat-item {
      display: flex;
      flex-direction: column;
      align-items: center;

      .stat-value {
        font-size: 24px;
        font-weight: 700;
        color: #303133;
      }

      .stat-label {
        font-size: 12px;
        color: #909399;
        margin-top: 4px;
      }
    }
  }

  // 伪类
  &:hover {
    border-color: #409eff;
    box-shadow: 0 2px 8px rgba(64, 158, 255, 0.15);
  }

  // 父级修饰符
  &--disabled {
    opacity: 0.5;
    pointer-events: none;
  }
}
```

### 4.3 禁止事项

- 禁止在 SCSS 中添加注释（代码即文档，选择器语义足够清晰）
- 禁止使用 `!important`（确有需要时通过提高选择器权重解决）
- 禁止使用 ID 选择器（`#xxx`）
- 禁止嵌套超过 3 层

### 4.4 变量与 Mixin

- 全局 SCSS 变量定义在 `src/styles/variables.scss`
- 全局 Mixin 定义在 `src/styles/mixins.scss`
- 通过 Vite 配置自动注入，不使用 `@import`

```scss
// src/styles/variables.scss — 全局变量
$color-primary: #409eff;
$color-success: #67c23a;
$color-warning: #e6a23c;
$color-danger: #f56c6c;
$color-text-primary: #303133;
$color-text-regular: #606266;
$color-text-secondary: #909399;
$border-color-base: #dcdfe6;
$border-radius-base: 4px;
$spacing-base: 16px;
```

```scss
// src/styles/mixins.scss — 全局 Mixin
@mixin text-ellipsis {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

@mixin flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

```typescript
// vite.config.ts — 自动注入
css: {
  preprocessorOptions: {
    scss: {
      additionalData: `
        @use "@/styles/variables.scss" as *;
        @use "@/styles/mixins.scss" as *;
      `,
    },
  },
},
```

### 4.5 scoped 样式

- 组件样式默认使用 `<style lang="scss" scoped>`
- 需要穿透 Element Plus 内部样式时使用 `:deep()`

```scss
<style lang="scss" scoped>
.data-source-form {
  .el-input {
    width: 100%;
  }

  // 穿透 Element Plus 内部样式
  :deep(.el-form-item__label) {
    font-weight: 600;
  }

  :deep(.el-select .el-input__wrapper) {
    border-radius: 0;
  }
}
</style>
```

## 5. 状态管理 (Pinia)

### 5.1 Store 命名

- 文件名：`src/stores/<name>.ts`，kebab-case
- Store 名称：use + PascalCase + Store，如 `useDataSourceStore`

```typescript
// src/stores/data-source.ts
import { defineStore } from 'pinia';

export const useDataSourceStore = defineStore('dataSource', () => {
  const list = ref<DataSource[]>([]);
  const loading = ref(false);

  async function fetchList() {
    loading.value = true;
    try {
      const res = await getDataSourceList();
      list.value = res.data.items;
    } finally {
      loading.value = false;
    }
  }

  return { list, loading, fetchList };
});
```

## 6. API 请求层

### 6.1 请求封装

```typescript
// src/api/request.ts
import axios from 'axios';
import type { AxiosResponse } from 'axios';
import { ElMessage } from 'element-plus';

const request = axios.create({
  baseURL: '/api/v1',
  timeout: 30000,
});

// 响应拦截：统一错误处理
request.interceptors.response.use(
  (response: AxiosResponse<ApiResponse>) => {
    const { code, message, msg, data } = response.data;
    if (code !== 0) {
      // msg 是中文用户提示，直接展示；message 是英文技术标识，仅日志记录
      ElMessage.error(msg || '请求失败');
      console.error(`[API Error] code=${code}, message=${message}`, msg);
      return Promise.reject(new Error(msg));
    }
    return data;
  },
  (error) => {
    ElMessage.error(error.message || '网络错误');
    return Promise.reject(error);
  }
);

export default request;
```

### 6.2 接口模块

```typescript
// src/api/data-source.ts
import request from './request';
import type { DataSource, DataSourceFormData } from '@/types/data-source';
import type { PaginatedResponse } from '@/types/common';

/** 获取数据源列表 */
export function getDataSourceList(params?: Record<string, unknown>): Promise<PaginatedResponse<DataSource>> {
  return request.get('/data-sources', { params });
}

/** 创建数据源 */
export function createDataSource(data: DataSourceFormData): Promise<DataSource> {
  return request.post('/data-sources', data);
}
```

## 8. 文件导入导出规范

### 8.1 模块统一导出（index 文件）

同一模块下的文件，使用 `index.ts` 统一导出：

```typescript
// ✅ src/types/index.ts — 统一导出所有类型
export type { DataSource, DataSourceFormData } from './data-source';
export type { IngestionBatch, IngestionTask } from './ingestion-task';
export type { ApiResponse, PaginatedData } from './common';
```

```typescript
// ✅ src/composables/index.ts — 统一导出所有 composable
export { usePagination } from './use-pagination';
export { useTableFilter } from './use-table-filter';
export { usePermission } from './use-permission';
```

```typescript
// ✅ src/api/index.ts — 统一导出所有 API 模块
export * from './data-source';
export * from './ingestion-task';
export * from './ingestion-batch';
```

### 8.2 导入路径规则

#### `.ts` / `.tsx` 文件

- 使用 `@/` 别名，省略 `index.ts`：

```typescript
// ✅ 省略 index.ts
import { usePagination } from '@/composables';
import type { DataSource } from '@/types';
import { getDataSourceList } from '@/api';

// ✅ 等价于：
import { usePagination } from '@/composables/index';
import type { DataSource } from '@/types/index';
import { getDataSourceList } from '@/api/index';
```

- 如果目标文件不是 `index.ts`，写完整路径（省略 `.ts` 后缀）：

```typescript
import { formatDate } from '@/utils/format';
import { TokenBucket } from '@/utils/rate-limiter';
```

#### `.vue` 文件

- `.vue` 文件**不支持**省略 `index.vue` 的路径简写，必须写完整路径：

```vue
<script setup lang="ts">
// ✅ .vue 文件：写完整路径
import StatusTag from '@/components/status-tag/index.vue';
import PageHeader from '@/components/page-header/index.vue';

// ❌ .vue 不能省略 index.vue（构建工具无法自动解析）
import StatusTag from '@/components/status-tag';
</script>
```

- 相对路径同理：

```vue
<script setup lang="ts">
import TaskForm from './components/task-form/index.vue';
import BatchLog from './components/batch-log/index.vue';
</script>
```

### 8.3 组件目录动态注册

当 `components/` 目录下文件较多（≥ 5 个），使用 `index.ts` 统一注册导出：

```typescript
// src/components/index.ts — 动态注册全局组件

import type { App } from 'vue';

// 需要全局注册的组件
const components: Record<string, Component> = import.meta.glob(
  './**/index.vue',
  { eager: true, import: 'default' }
);

export function registerGlobalComponents(app: App) {
  Object.entries(components).forEach(([path, component]) => {
    const name = path
      .split('/')
      .filter(p => p !== '.' && p !== 'index.vue')
      .pop();
    if (name && component) {
      app.component(name, component as Component);
    }
  });
}
```

```typescript
// main.ts
import { registerGlobalComponents } from '@/components';
registerGlobalComponents(app);
```

**但页面级组件（`views/`）不做动态注册**，页面组件使用路由懒加载即可。

### 8.4 导入路径速查

| 目标文件类型 | 是 index 文件时 | 非 index 文件时 |
|---|---|---|
| `.ts` / `.tsx` | `@/types`（省略 index） | `@/utils/format`（省略 .ts） |
| `.vue` | `@/components/status-tag/index.vue`（**不可省略**） | `@/views/data-source/detail.vue` |
| `.scss` | `@/styles`（如有 index.scss） | `@/styles/variables.scss` |
