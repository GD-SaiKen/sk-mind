## 1. 模块结构

每个业务模块必须包含以下标准分层，不得跨层直接访问：

```text
app/modules/{module_name}/
├── __init__.py
├── models/          # SQLAlchemy ORM 模型（数据访问层）
├── schemas/         # Pydantic 请求/响应模型（接口层）
├── services/        # 业务逻辑（服务层）
├── api/             # FastAPI 路由（控制器层）
└── tasks/           # RQ 异步任务入口（仅需要异步时）
```

### 1.1 分层职责

| 层 | 职责 | 允许调用 |
|---|---|---|
| **api/** | 处理 HTTP 请求参数、鉴权、响应格式和错误码 | services |
| **services/** | 业务规则、状态流转、跨模块编排 | models, 其他模块的 services |
| **models/** | SQLAlchemy 模型定义、基础查询方法 | 仅 ORM |
| **tasks/** | RQ Worker 任务入口，调用 services | services |

```python
# ✅ api 层只处理请求/响应
@router.get("/{source_id}")
def get_data_source(source_id: int, db: Session = Depends(get_db)):
    service = DataSourceService(db)
    result = service.get_by_id(source_id)
    if not result:
        raise HTTPException(status_code=404, detail="数据源不存在")
    return success_response(data=result)

# ❌ api 层直接操作数据库
@router.get("/{source_id}")
def get_data_source(source_id: int, db: Session = Depends(get_db)):
    return db.query(DataSource).filter(DataSource.id == source_id).first()  # 不对
```

### 1.2 `__init__.py` 导出规范

Python 的 `__init__.py` 直接对应前端 `index.ts` 的统一导出机制。每个模块目录必须通过 `__init__.py` 控制对外暴露的接口。

**核心原则**：

- `__init__.py` 明确列出对外公开的符号，控制模块的公开 API 面
- 内部实现细节（私有函数、基类、工具函数）不对外暴露
- 外部调用方通过模块路径导入，不绕过 `__init__.py` 直接引用内部文件

```python
# ✅ app/modules/ingestion/__init__.py — 对外暴露的公共接口

from app.modules.ingestion.services.data_source import DataSourceService
from app.modules.ingestion.services.ingestion_task import IngestionTaskService
from app.modules.ingestion.services.sync_service import SyncService

__all__ = [
    "DataSourceService",
    "IngestionTaskService",
    "SyncService",
]
```

```python
# ✅ app/modules/ingestion/services/__init__.py

from app.modules.ingestion.services.data_source import DataSourceService
from app.modules.ingestion.services.ingestion_task import IngestionTaskService
from app.modules.ingestion.services.sync_service import SyncService
```

```python
# ✅ app/modules/ingestion/connectors/__init__.py

from app.modules.ingestion.connectors.sqlserver import SqlServerConnector
from app.modules.ingestion.connectors.api_client import HttpxApiConnector

__all__ = ["SqlServerConnector", "HttpxApiConnector"]
```

**调用方导入规则**：

```python
# ✅ 通过模块路径导入（利用 __init__.py 的重导出）
from app.modules.ingestion import DataSourceService, SyncService
from app.modules.ingestion.connectors import SqlServerConnector

# ✅ 同包内相对导入（仅在模块内部使用）
from .services.sync_service import SyncService
from .models.ingestion_batch import IngestionBatch

# ❌ 绕过 __init__.py 直接引用内部文件
from app.modules.ingestion.services.data_source import DataSourceService  # 不推荐
from app.modules.ingestion.connectors.sqlserver import SqlServerConnector  # 不推荐
```

**例外情况**：以下场景允许绕过 `__init__.py` 直接导入：

- 同包内的 models 互相引用（避免循环导入）
- tasks/ 目录下的 RQ 任务入口（需要完整模块路径供 RQ Worker 反序列化）

```python
# ✅ tasks/ 中的 RQ 任务入口：必须使用完整模块路径
job = task_queue.enqueue(
    "app.modules.ingestion.tasks.full_sync.run_full_sync",  # 完整路径
    task_id, source_object_id, batch_id,
)
```

## 2. 数据模型 (models/)

### 2.1 模型定义

- 使用 SQLAlchemy 2.0 Mapped 语法
- 表名统一小写 + 下划线，手动指定 `__tablename__`
- 每个模型必须包含 `id`、`created_at`、`updated_at`

```python
from datetime import datetime
from sqlalchemy import String, Text, func
from sqlalchemy.orm import Mapped, mapped_column

from app.core.database import Base

class DataSource(Base):
    __tablename__ = "data_source"

    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String(128), nullable=False, comment="数据源名称")
    source_type: Mapped[str] = mapped_column(String(32), nullable=False, comment="database/api/file")
    status: Mapped[str] = mapped_column(String(32), default="active", comment="active/inactive/error")
    owner: Mapped[str] = mapped_column(String(64), nullable=True, comment="负责人")
    tags: Mapped[dict | None] = mapped_column(JSONB, nullable=True, comment="标签")
    risk_notes: Mapped[str | None] = mapped_column(Text, nullable=True, comment="风险说明")
    created_at: Mapped[datetime] = mapped_column(default=func.now(), comment="创建时间")
    updated_at: Mapped[datetime] = mapped_column(default=func.now(), onupdate=func.now(), comment="更新时间")
```

- 所有字段必须写 `comment`（数据库注释），使用中文
- 可为 NULL 的字段必须显式 `nullable=True`

### 2.2 外键与关系

```python
class IngestionBatch(Base):
    __tablename__ = "ingestion_batch"

    id: Mapped[int] = mapped_column(primary_key=True)
    task_id: Mapped[int] = mapped_column(ForeignKey("ingestion_task.id"), comment="关联任务ID")
    batch_id: Mapped[str] = mapped_column(String(64), unique=True, comment="批次标识")

    # 关系定义（仅在需要 ORM 级联查询时声明）
    task: Mapped["IngestionTask"] = relationship(back_populates="batches")
```

- SQLAlchemy 模型使用单数类名（`DataSource`），表名用复数或业务名（`data_source`）
- 外键字段命名：`{关联表}_id`

## 3. Schemas (schemas/)

### 3.1 请求/响应模型

- 使用 Pydantic v2 语法
- 请求和响应分开定义，避免复用导致的字段泄漏

```python
from pydantic import BaseModel, Field
from datetime import datetime

# --- 请求 ---
class DataSourceCreate(BaseModel):
    """创建数据源请求"""
    name: str = Field(..., max_length=128, description="数据源名称")
    source_type: str = Field(..., description="database/api/file")
    owner: str | None = Field(None, max_length=64, description="负责人")

class DataSourceUpdate(BaseModel):
    """更新数据源请求（所有字段可选）"""
    name: str | None = Field(None, max_length=128, description="数据源名称")
    status: str | None = Field(None, description="active/inactive/error")
    owner: str | None = Field(None, max_length=64, description="负责人")

# --- 响应 ---
class DataSourceResponse(BaseModel):
    """数据源响应"""
    id: int
    name: str
    source_type: str
    status: str
    owner: str | None
    created_at: datetime
    updated_at: datetime

    model_config = {"from_attributes": True}
```

## 4. 服务层 (services/)

### 4.1 服务类结构

- 每个模块一个主服务类，通过 `__init__` 注入数据库 session
- 服务方法职责单一，命名动宾结构

```python
class DataSourceService:
    """数据源管理服务"""

    def __init__(self, db: Session):
        self.db = db

    def get_by_id(self, source_id: int) -> DataSource | None:
        """按 ID 查询数据源"""
        return self.db.get(DataSource, source_id)

    def list_sources(
        self,
        keyword: str | None = None,
        source_type: str | None = None,
        status: str | None = None,
        page: int = 1,
        page_size: int = 20,
    ) -> tuple[list[DataSource], int]:
        """分页查询数据源列表"""
        query = self.db.query(DataSource)
        if keyword:
            query = query.filter(DataSource.name.ilike(f"%{keyword}%"))
        if source_type:
            query = query.filter(DataSource.source_type == source_type)
        if status:
            query = query.filter(DataSource.status == status)

        total = query.count()
        items = query.order_by(DataSource.updated_at.desc()) \
                     .offset((page - 1) * page_size) \
                     .limit(page_size) \
                     .all()
        return items, total

    def create(self, data: DataSourceCreate) -> DataSource:
        """创建数据源"""
        source = DataSource(**data.model_dump())
        self.db.add(source)
        self.db.commit()
        self.db.refresh(source)
        return source

    def update(self, source_id: int, data: DataSourceUpdate) -> DataSource | None:
        """更新数据源"""
        source = self.get_by_id(source_id)
        if not source:
            return None
        update_data = data.model_dump(exclude_unset=True)
        for key, value in update_data.items():
            setattr(source, key, value)
        self.db.commit()
        self.db.refresh(source)
        return source

    def delete(self, source_id: int) -> bool:
        """删除数据源"""
        source = self.get_by_id(source_id)
        if not source:
            return False
        self.db.delete(source)
        self.db.commit()
        return True
```

## 5. API 路由 (api/)

### 5.1 路由定义

```python
from fastapi import APIRouter, Depends, HTTPException, Query
from sqlalchemy.orm import Session

from app.core.database import get_db
from app.modules.ingestion.schemas.data_source import (
    DataSourceCreate,
    DataSourceResponse,
    DataSourceUpdate,
)
from app.modules.ingestion.services.data_source import DataSourceService

router = APIRouter(prefix="/data-sources", tags=["数据源管理"])


@router.get("", response_model=PaginatedResponse[DataSourceResponse])
def list_data_sources(
    keyword: str | None = Query(None, description="搜索关键词"),
    source_type: str | None = Query(None, description="数据源类型"),
    page: int = Query(1, ge=1, description="页码"),
    page_size: int = Query(20, ge=1, le=100, description="每页数量"),
    db: Session = Depends(get_db),
):
    """分页查询数据源列表"""
    service = DataSourceService(db)
    items, total = service.list_sources(keyword, source_type, page=page, page_size=page_size)
    return paginated_response(items=items, total=total, page=page, page_size=page_size)


@router.post("", response_model=DataSourceResponse, status_code=201)
def create_data_source(
    data: DataSourceCreate,
    db: Session = Depends(get_db),
):
    """创建数据源"""
    service = DataSourceService(db)
    return service.create(data)


@router.get("/{source_id}", response_model=DataSourceResponse)
def get_data_source(source_id: int, db: Session = Depends(get_db)):
    """获取数据源详情"""
    service = DataSourceService(db)
    result = service.get_by_id(source_id)
    if not result:
        raise HTTPException(status_code=404, detail="数据源不存在")
    return result


@router.put("/{source_id}", response_model=DataSourceResponse)
def update_data_source(
    source_id: int,
    data: DataSourceUpdate,
    db: Session = Depends(get_db),
):
    """更新数据源"""
    service = DataSourceService(db)
    result = service.update(source_id, data)
    if not result:
        raise HTTPException(status_code=404, detail="数据源不存在")
    return result


@router.delete("/{source_id}", status_code=204)
def delete_data_source(source_id: int, db: Session = Depends(get_db)):
    """删除数据源"""
    service = DataSourceService(db)
    if not service.delete(source_id):
        raise HTTPException(status_code=404, detail="数据源不存在")
```

### 5.2 统一响应函数

```python
# app/api/v1/__init__.py 或 app/core/response.py

from typing import Generic, TypeVar

T = TypeVar("T")

class ApiResponse(BaseModel, Generic[T]):
    code: int = 0
    message: str = "success"         # 英文技术状态
    msg: str = "操作成功"             # 中文用户提示
    data: T | None = None

class PaginatedData(BaseModel, Generic[T]):
    items: list[T]
    total: int
    page: int
    pageSize: int                     # camelCase（与前端 DB 字段约定一致）

def success_response(
    data: T = None,
    message: str = "success",
    msg: str = "操作成功",
) -> ApiResponse[T]:
    return ApiResponse(code=0, message=message, msg=msg, data=data)

def error_response(
    code: int,
    message: str,                    # 英文: "connection_failed"
    msg: str,                        # 中文: "连接失败：无法连接到..."
    detail: str = "",
) -> ApiResponse[None]:
    return ApiResponse(code=code, message=message, msg=msg, data=None)

def paginated_response(**kwargs) -> ApiResponse[PaginatedData]:
    return ApiResponse(
        message="success",
        msg="查询成功",
        data=PaginatedData(
            items=kwargs["items"],
            total=kwargs["total"],
            page=kwargs["page"],
            pageSize=kwargs["pageSize"],
        ),
    )
```

## 6. 异步任务 (tasks/)

### 6.1 RQ 任务编写

```python
# app/modules/ingestion/tasks/full_sync.py

from rq import get_current_job
from sqlalchemy.orm import Session

from app.core.database import SessionLocal
from app.modules.ingestion.services.sync_service import SyncService


def run_full_sync(task_id: int, source_object_id: int, batch_id: str):
    """
    RQ 任务：执行全量同步。

    由 TaskService 入队，Worker 异步执行。执行过程中通过 RQ job.meta
    更新进度百分比和当前步骤描述，管理台可通过 job_id 轮询进度。
    """
    job = get_current_job()
    db = SessionLocal()
    try:
        service = SyncService(db)
        service.execute_full_sync(task_id, source_object_id, batch_id, job)
    except Exception as e:
        # 标记批次失败
        service.mark_batch_failed(batch_id, str(e))
        raise
    finally:
        db.close()
```

### 6.2 Worker 启动

```python
from app.core.config import settings


def main():
```

## 7. 数据库与 Alembic 迁移

### 7.1 Session 管理

```python
# app/core/database.py

from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, Session, sessionmaker

from app.core.config import settings

engine = create_engine(
    settings.DATABASE_URL,
    pool_size=10,
    max_overflow=20,
    pool_pre_ping=True,       # 检测断连
)

SessionLocal = sessionmaker(bind=engine, autocommit=False, autoflush=False)


class Base(DeclarativeBase):
    pass


def get_db() -> Session:
    """FastAPI 依赖注入：获取数据库 session"""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

### 7.2 Alembic 迁移

- 每次模型变更必须生成迁移文件
- 迁移文件必须经过 Review
- 迁移文件名使用描述性短语

```bash
# 生成迁移
```

## 8. PostgreSQL 数据库规范

### 8.1 单库多 Schema

```text
PostgreSQL 实例
  └── skmind（单数据库）
        ├── platform   — 平台元数据（data_source, ingestion_task, agent_session ...）
        ├── raw        — 原始数据层（erp_*, api_record）
        ├── clean      — 清洗数据层
        └── serving    — 服务视图/物化视图
```

### 8.2 表命名

| Schema | 命名格式 | 示例 |
|---|---|---|
| `platform` | 业务语义命名 | `data_source`, `ingestion_task`, `ingestion_batch` |
| `raw` | `{系统}_{源表名}` 或 `api_record` | `raw.erp_dbo_sale_order`, `raw.api_record` |
| `clean` | 与 raw 层同名 | `clean.erp_dbo_sale_order` |
| `serving` | `v_{业务对象}` | `serving.v_sales_order` |

### 8.3 字段类型选择

| 场景 | 推荐类型 | 说明 |
|---|---|---|
| 主键 | `BIGSERIAL` 或 `BIGINT` | 业务表都用 BIGINT |
| 短文本 | `VARCHAR(n)` | n 按实际需求，不滥用 `VARCHAR(255)` |
| 长文本 | `TEXT` | 超过 4000 字节 |
| JSON | `JSONB` | 需要查询内部字段时用 JSONB |
| 时间戳 | `TIMESTAMPTZ` | 统一使用带时区的时间戳 |
| 布尔 | `BOOLEAN` | |
| 金额 | `NUMERIC(19,4)` | 避免浮点精度问题 |
| 状态/枚举 | `VARCHAR(32)` | 不用数据库枚举类型，方便扩展 |

### 8.4 索引规范

- 外键必须建索引
- 按时间范围查询的字段建索引（`_ingested_at`, `_batch_id`）
- JSONB 字段如需内部查询，建 GIN 索引
- 索引命名：`idx_{表名}_{字段1}_{字段2}`

```sql
CREATE INDEX idx_ingestion_batch_task    ON platform.ingestion_batch (task_id);
CREATE INDEX idx_ingestion_batch_status  ON platform.ingestion_batch (status);
CREATE INDEX idx_raw_record_batch        ON raw.api_record (_batch_id);
CREATE INDEX idx_raw_record_payload      ON raw.api_record USING GIN (payload jsonb_path_ops);
```

```python
# app/core/exceptions.py

class AppException(Exception):
    """应用级异常基类"""
    def __init__(self, message: str, code: int = 50000):
        self.message = message
        self.code = code


class ConnectionFailedError(AppException):
    """数据源连接失败"""
    def __init__(self, source_name: str, detail: str = ""):
        super().__init__(
            message=f"连接数据源 [{source_name}] 失败：{detail}",
            code=40001,
        )


class SyncFailedError(AppException):
    """同步任务执行失败"""
    def __init__(self, task_name: str, detail: str = ""):
        super().__init__(
            message=f"同步任务 [{task_name}] 执行失败：{detail}",
            code=40002,
        )


class PermissionDeniedError(AppException):
    """权限不足"""
    def __init__(self, resource: str = ""):
        super().__init__(
            message=f"权限不足，无法访问 {resource}" if resource else "权限不足",
            code=40300,
        )
```

```python
def setup_logging():
```

```python
import logging

logger = logging.getLogger(__name__)

# 正常流程
logger.info("全量同步开始: task_id=%d, table=%s, total_rows=%d", task_id, table, total)

# 异常
logger.error("连接数据源失败: source=%s, error=%s", source_name, str(e))

# 调试（仅开发环境）
logger.debug("批次写入完成: batch_id=%s, rows=%d", batch_id, len(records))
```

```python
# tests/modules/ingestion/test_data_source_service.py

import pytest
from sqlalchemy.orm import Session

from app.modules.ingestion.services.data_source import DataSourceService


def test_create_data_source_success(db: Session):
    """创建数据源 — 正常流程"""
    service = DataSourceService(db)
    result = service.create(DataSourceCreate(
        name="测试ERP",
        source_type="database",
    ))
    assert result.id is not None
    assert result.name == "测试ERP"


def test_create_data_source_duplicate_name(db: Session):
    """创建数据源 — 重名校验"""
    service = DataSourceService(db)
    service.create(DataSourceCreate(name="测试ERP", source_type="database"))
    with pytest.raises(DuplicateError):
        service.create(DataSourceCreate(name="测试ERP", source_type="api"))


def test_delete_data_source_not_found(db: Session):
    """删除数据源 — 不存在"""
    service = DataSourceService(db)
    result = service.delete(99999)
    assert result is False
```
