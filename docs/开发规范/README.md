## 执行原则

1. **默认遵循**：所有新增代码必须遵循本规范，Code Review 时对照检查
2. **存量优先**：修改已有文件时，若原文件存在不同的局部约定，优先保持文件内风格一致，并在变更摘要中说明
3. **中文沟通**：团队内沟通、文档、PR 描述、代码注释统一使用中文
4. **中文 UI**：前端界面文案默认使用中文，除非用户明确要求其他语言
